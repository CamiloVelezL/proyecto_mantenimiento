## 1. Información General
*   **Problema seleccionado:** Gestión de fallas y mantenimiento correctivo de instalaciones.
*   **Nota de trabajo:** El proyecto se desarrolla de forma individual. Se aplicará un flujo de Git con ramas y Pull Requests simulando un entorno colaborativo.

## 2. Descripción del Sistema
*   **Problema abordado:** Centralizar los reportes de fallas dispersos, permitiendo el seguimiento desde el reporte hasta el cierre.
*   **Actores:** Reportante, Personal de Mantenimiento, Coordinación.
*   **Alcance:** Gestión de reportes, asignaciones e intervenciones. Sin inventarios ni compras.
